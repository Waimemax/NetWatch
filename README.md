
# NetWatch

NetWatch is a Python-based network discovery and monitoring CLI tool designed to help users identify devices on authorized local networks, inspect selected TCP ports, and generate structured reports.

## Features

- Local network discovery
- TCP port scanning
- Basic service identification
- JSON and CSV reporting
- Network discovery snapshots
- Comparison of network changes

## Technologies

- Python
- pytest
- Ruff
- Rich

## Project Status

Under development.

## Ethical Use

NetWatch is intended for networks you own or have explicit permission to assess. Unauthorized scanning is prohibited.
